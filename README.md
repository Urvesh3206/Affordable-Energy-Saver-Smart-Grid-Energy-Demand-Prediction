# Affordable Energy Saver – Smart Grid Energy Demand Prediction

## 📌 Project Overview
This project predicts energy demand using Machine Learning and Streamlit.

## 🚀 Features
- Energy demand prediction
- High demand classification
- Interactive Streamlit web app

## 🛠 Technologies Used
- Python
- Streamlit
- Scikit-learn
- Pandas
- NumPy

## ▶️ How to Run

```bash
pip install -r requirements.txt
streamlit run app.py
